# Aset grafis Sandbox Chip

- `logomark.svg` — penanda IT Agenty untuk Sandbox Chip Merah Putih.
- `favicon-32.png` — salinan lokal favicon asli PERURI.
- `icon-192.png`, `icon-512.png` — ikon PWA yang dibuat dari `logomark.svg`
  memakai Chromium headless, sehingga bisa dipasang sebagai aplikasi.

Berkas PNG tidak menyimpan header teks; lisensi karya IT Agenty dinyatakan
di berkas ini dan di manifest aplikasi.

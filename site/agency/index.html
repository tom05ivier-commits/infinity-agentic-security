Infinity Security Suite

Satu sistem, seluruh kebutuhan keamanan.

Setiap komponen berjalan sebagai proses yang diawasi supervisor dan dapat di-hot-reload tanpa restart container.

⛨

Firewall

Policy userspace dengan opsi enforcement kernel via iptables bila capability tersedia.

✚

Antivirus

Deteksi berbasis tanda tangan EICAR yang jinak — aman untuk latihan dan drill.

◫

DLP

Hanya deteksi dan karantina paparan data. Tidak pernah mencuri atau mengirim data.

✓

Integritas

Baseline dan pemantauan berkas untuk mendeteksi perubahan yang tidak diinginkan.

◎

SOC

Laporan verifikasi, kampanye, insiden, dan efficacy dalam satu tempat.

⚑

Red team

Simulasi ofensif hanya di lab/localhost dengan otorisasi eksplisit dan batas waktu.

Arsitektur

Sederhana di luar, disiplin di dalam.

01

Supervisor always-on

Membaca system/services.json tiap siklus. Server baru langsung hidup, yang dihapus otomatis berhenti.

02

Lokal by design

Bind ke 127.0.0.1, tunnel dan akses publik dimatikan. Tidak ada server "liar" di luar registry.

03

Volume persisten

Laporan, log, karantina, dan aturan firewall disimpan di volume Docker agar tidak hilang saat restart.

04

Sumber daya terkendali

512 MB / 1 CPU di produksi, 256 MB / 0,5 CPU di mode dev — semua statis dan tanpa CDN.

Lisensi & otorisasi

Aturan yang sama untuk semua karya.

Setiap file baru memuat header SPDX dan copyright. Kode pihak ketiga tetap tunduk pada lisensi asalnya.

Cara pakai subdomain lokal

  1. Daftarkan nama di halaman generator, misalnya ai-chip.
  2. Tekan tombol pemasangan lalu konfirmasi. Blok # BEGIN AGENTY-LOCAL-DOMAINS ditulis ke /etc/hosts dengan backup.
  3. Buka http://ai-chip.agenty.local:8783/status di perangkat ini.

Subdomain ini hanya berfungsi di perangkat tempat blok hosts dipasang, bukan DNS publik.

Cara pakai Dynamic DNS

Siapkan akun di penyedia, simpan token di environment, lalu jalankan:

python3 system/domain_cli.py ddns-status
python3 system/domain_cli.py ddns-update --provider duckdns --domain nama.duckdns.org --authorize --ttl 120

Tanpa --authorize, perintah ditolak. Token tidak pernah dicetak atau disimpan oleh IT Agenty.

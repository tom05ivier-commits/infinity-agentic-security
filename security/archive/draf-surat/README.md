# Arsip draf surat

Berisi draf surat izin yang **tidak pernah berlaku** dan tidak dirujuk oleh
kode maupun dokumentasi proyek. Dipindahkan dari root workspace pada
23 November 2026 untuk merapikan direktori tanpa menghapus jejak.

Draf yang masih dirujuk oleh `system/license_formalization.py`,
`system/tests/test_tom05_ctl.py`, `system/hy4_manager.py`, `AGENTS.md`, atau
`docs/` sengaja **tetap tinggal di root**. Memindahkannya akan memutus
referensi dan menggagalkan pengujian.

Arsip ini bukan otoritas baru. Berkas di sini tidak mengubah lisensi, izin,
atau tanda tangan pemilik.

`surat-izin-bobot-gpu-tom05.md` dikembalikan ke root workspace karena
`security/reports/authorization_revocations.jsonl` mencatat status **AKTIF**
(aktivasi kembali 24 November 2026). Berkas ini bukan draf dan tidak boleh
dianggap tidak berlaku.
